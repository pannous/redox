## 🤖 Assistant

Implemented variadic function support for Cranelift! 

**Summary of changes:**

1. **`src/common.rs`**: Added `va_list_slot: Option<Pointer>` field to `FunctionCx` for tracking the variadic argument pointer storage.

2. **`src/abi/mod.rs`**: 
   - Added `setup_va_list()` function that allocates platform-specific va_list storage
   - Implemented special handling for `ArgKind::VaList` in `codegen_fn_prelude`
   - VaList is initialized with `FP+16` (the address of first vararg on stack)

3. **`src/intrinsics/mod.rs`**: Implemented the va_* intrinsics:
   - `va_start`: No-op (initialization happens in prelude)
   - `va_arg`: Reads value from current pointer, advances by argument size
   - `va_copy`: Copies pointer value from source to destination
   - `va_end`: No-op

4. **`example/std_example.rs`**: Added test for variadic functions

**Platforms supported:**
- Apple AArch64 (macOS/iOS arm64)
- Windows x64
- UEFI

These platforms use a simple va_list that's just a pointer. Complex va_list platforms (x86_64 System V, generic AArch64) are not yet supported.
