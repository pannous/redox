## Summary

**Fixed the virtio-blkd IRQ conflict!**

### Root Cause
During aarch64 IRQ chip initialization (GIC, GICv3, BCM2835, BCM2836), all IRQ descriptors were marked as `used = true`, which the kernel's IRQ scheme interpreted as "already reserved by a driver". This caused all driver IRQ opens to fail with `EEXIST (error 17)`.

### Fix
Changed all IRQ chip init code to set `used = false`:
```rust
// All 4 files: gic.rs, gicv3.rs, irq_bcm2835.rs, irq_bcm2836.rs
irq_desc[idx + i].basic.used = false;  // Available for driver reservation
```
