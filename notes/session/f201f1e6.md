## Risks and Considerations

### Technical Risks
1. **PSCI availability** - QEMU must support PSCI calls
   - Mitigation: QEMU virt machine includes PSCI by default

2. **Race conditions** - SMP exposes concurrency bugs
   - Mitigation: Extensive testing, enable kernel debugging

3. **Interrupt routing** - GIC configuration is complex
   - Mitigation: Study ARM GIC specifications, use x86 as reference

4. **Memory ordering** - aarch64 has weak memory model
   - Mitigation: Use proper barriers (ISB, DSB, DMB) in critical sections

### Dependencies
- QEMU custom build at `/opt/other/qemu/build/qemu-system-aarch64`
- Device tree blob with `/cpus` node populated
- EDK2 firmware with PSCI support
- GIC hardware (GICv2 or GICv3) in QEMU virt machine

### Out of Scope
- CPU hotplug (adding/removing CPUs at runtime)
- CPU frequency scaling / power management
- NUMA (Non-Uniform Memory Access) support
- More than 128 CPUs (current LogicalCpuSet limit)

pub fn handle_ipi(sgi_num: u32) {
    let kind = match sgi_num {
        0 => IpiKind::Wakeup,
        1 => IpiKind::Tlb,
        2 => IpiKind::Switch,
        3 => IpiKind::Pit,
        4 => IpiKind::Kstop,
        _ => return,
    };

            PercpuBlock::current().maybe_handle_tlb_shootdown();
        }
        IpiKind::Switch | IpiKind::Pit => {
            context::switch::tick();
        }
        IpiKind::Kstop => {
            loop { unsafe { interrupt::halt(); } }
        }

    }
}

    unsafe {
        let args = args_ptr.read();
        
        // Set up exception vectors
        core::arch::asm!("msr vbar_el1, {}", in(reg) &exception_vector_base);
        
        // Set up stack
        core::arch::asm!("mov sp, {}", in(reg) args.stack_end);
        
        // Configure MMU with BSP's page table
        core::arch::asm!("msr ttbr1_el1, {}", in(reg) args.page_table);
        core::arch::asm!("tlbi vmalle1");
        core::arch::asm!("dsb sy");
        core::arch::asm!("isb");
        
        // Initialize paging
        paging::init();
        
        // Initialize per-CPU state
        let cpu_id = crate::cpu_set::LogicalCpuId::new(args.cpu_id as u32);
        crate::misc::init(cpu_id);
        
        // Signal ready
        AP_READY.store(true, Ordering::SeqCst);
        
        // Wait for BSP
        while !BSP_READY.load(Ordering::SeqCst) {
            core::hint::spin_loop();
        }
        
        // Enter scheduler
        crate::kmain_ap(cpu_id);
