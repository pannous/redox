**Fixed!** The liner EAGAIN error is now resolved.

**Root cause:** The `change_blocking()` function in `ion/src/binary/readln.rs:9` was:
```rust
fcntl(fd, FcntlArg::F_SETFL(OFlag::O_RDWR)).unwrap();
```

This didn't work because `O_RDWR` is an access mode (used when opening files), not a status flag. It doesn't clear `O_NONBLOCK`.

**Fix:** Properly get current flags, clear the `O_NONBLOCK` bit, then set them back:
```rust
if let Ok(flags) = fcntl(fd, FcntlArg::F_GETFL) {
    let mut oflags = OFlag::from_bits_truncate(flags);
    oflags.remove(OFlag::O_NONBLOCK);
    let _ = fcntl(fd, FcntlArg::F_SETFL(oflags));
}
```

**This is the actual fix**, not a workaround. No forked liner needed - the bug was in ion's code. Tested in Redox and confirmed working.
