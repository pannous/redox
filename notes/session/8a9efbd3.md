## Summary

**The pcid-spawner "No such device" error is now FIXED!**

### What was the problem?
The issue had two parts:
1. The NO_FORK daemon mode I implemented blocked forever because daemon functions run infinite loops
2. When hwd started pcid and waited for it to exit, init would block indefinitely since pcid runs forever serving requests

### What was fixed?
1. **Restored proper fork()** in `daemon/src/lib.rs` using `libc::fork()` instead of the broken NO_FORK workaround
2. **Modified hwd** to spawn pcid without waiting for exit - just sleep 500ms for scheme registration
