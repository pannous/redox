**Fixed!** Summary:

**Problem**: randd only had x86_64 RDRAND entropy, so aarch64 had no entropy source.

**Solution**: Added timer jitter entropy using ARM's CNTVCT_EL0 virtual counter:
- Samples counter 64 times with busywork between samples
- Timing jitter from system activity provides entropy
- SHA256 mixes all samples into 32-byte seed for ChaCha20 CSPRNG

**Boot now shows**:
```
randd: Seeded from aarch64 timer jitter entropy
```

- `recipes/core/base/source/randd/src/main.rs` - aarch64 entropy code (gitignored)
