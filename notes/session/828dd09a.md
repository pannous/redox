```bash
# Redox: /scheme/9p.hostshare/
```

The 9p share is the cleanest solution for "always mounted" access - it's specifically designed for host↔guest file sharing while the VM runs. No corruption risk since it's a network protocol, not direct disk access.

If you want to leave a qcow2 mounted for convenience, just make sure QEMU isn't using that same file. You could keep a separate "staging" qcow2 mounted and periodically copy files into the running VM's image when it's stopped.
