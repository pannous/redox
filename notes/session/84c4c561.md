The hooks are working. Here's what's now configured:

| **PostToolUse** | After Edit/Write/NotebookEdit | WIP commit after file modifications |

**Files created:**
- `.claude/hooks/git-autocommit.sh` - The commit script using `./git-all.sh`

**Behavior:**
- Non-blocking: If no changes exist, silently continues
- Multi-repo: Uses `./git-all.sh` to commit across all component repos
- Message format: `wip: auto-save after Edit` or `wip: session checkpoint`

The test just committed pending changes across 5 repos (main, kernel, relibc, base, ion).

**Limitation:** There's no periodic/interval hook in Claude Code - only event-based. The "every once in a while" is approximated by committing after each file edit. If you need true periodic commits (e.g., every 5 minutes), you'd need to run a background cron/timer outside Claude Code.
