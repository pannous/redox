The pure Rust ISO (earlier successful boot) worked because both kernel and initfs were from the same build chain. The later crash happened when we mixed Cranelift kernel with a different initfs format.

For virtio-net to work, we need to inject the fixed driver into an ISO that also uses the Cranelift kernel. Since the Cranelift kernel crashed with the larger initfs, there may be a memory mapping issue in the Cranelift kernel that needs investigation.
